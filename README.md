# Convite da Giulia · 15 anos

Convite estático com envelope animado, selo prateado, brilhos e música do YouTube.

Festa em 20 de novembro de 2026, sexta-feira, às 21h. Local: Salão de festas LaBelle Maison. O ícone de localização, à esquerda do nome do local, abre o Google Maps. Não há confirmação de presença.

Para visualizar localmente, execute na raiz do projeto:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Abra `http://127.0.0.1:8000/`. Para conferir a sintaxe do JavaScript: `node --check script.js`.

Para publicar: Settings → Pages → Deploy from a branch → main → / (root).
